# Module: `rds`

**Managed PostgreSQL, private and encrypted**

Creates the DB subnet group, a parameter group enforcing TLS, and an encrypted RDS instance that is not publicly accessible. The master password is generated by RDS and stored in Secrets Manager - it never enters Terraform state.

## Usage

```hcl
module "rds" {
  source = "../../modules/rds"

  name_prefix = local.name_prefix
  # ... see variables below
}
```

## Inputs

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name_prefix` | `string` | **yes** | Prefix applied to all resource names, e.g. 'myapp-dev'. |
| `db_subnet_ids` | `list(string)` | **yes** | Private database subnet IDs. Minimum two AZs, even for a single-AZ instance. |
| `security_group_id` | `string` | **yes** | Security Group for the database. Should permit the application tier only. |
| `engine` | `string` | no | Database engine. |
| `engine_version` | `string` | no | Engine major version. Specify only the major version so AWS selects the latest supported minor release. |
| `parameter_group_family` | `string` | no | Parameter group family. Must match the engine version, e.g. postgres16. |
| `instance_class` | `string` | no | Instance class. A primary cost lever between environments. |
| `allocated_storage` | `number` | no | Initial storage in GB. Minimum 20 for most engines. |
| `max_allocated_storage` | `number` | no | Ceiling for storage autoscaling in GB. Set equal to allocated_storage to disable autoscaling. |
| `storage_type` | `string` | no | Storage type. gp3 offers better baseline performance than gp2 at similar cost. |
| `kms_key_id` | `string` | no | Customer-managed KMS key ARN for encryption at rest. Null uses the AWS-managed RDS key, which is free. |
| `database_name` | `string` | no | Name of the initial database created on the instance. |
| `master_username` | `string` | no | Master username. The PASSWORD is generated by RDS and stored in Secrets Manager - it is never set here. |
| `port` | `number` | no | Database port. 5432 for PostgreSQL, 3306 for MySQL. |
| `multi_az` | `bool` | no | Run a synchronous standby in a second AZ with automatic failover. DOUBLES the instance cost. Production only. |
| `backup_retention_period` | `number` | no | Days to retain automated backups. 0 disables backups and point-in-time recovery entirely - never use 0 in production. |
| `backup_window` | `string` | no | Daily backup window in UTC, format hh:mm-hh:mm. Choose a low-traffic period. |
| `maintenance_window` | `string` | no | Weekly maintenance window in UTC, format ddd:hh:mm-ddd:hh:mm. Must not overlap the backup window. |
| `deletion_protection` | `bool` | no | Prevent deletion of the instance. Must be disabled and applied before a genuine teardown. |
| `skip_final_snapshot` | `bool` | no | Skip the final snapshot on deletion. True in dev to avoid orphaned snapshots that keep billing; false in production. |
| `final_snapshot_suffix` | `string` | no | Suffix making the final snapshot identifier unique. Pass a timestamp or build number - reusing an existing snapshot name causes destroy to fail. |
| `enabled_cloudwatch_logs_exports` | `list(string)` | no | Log types to publish to CloudWatch. For PostgreSQL: postgresql, upgrade. |
| `performance_insights_enabled` | `bool` | no | Enable Performance Insights. Free at 7-day retention. |
| `performance_insights_retention_period` | `number` | no | Performance Insights retention in days. 7 is free; longer is billed. |
| `monitoring_interval` | `number` | no | Enhanced Monitoring granularity in seconds (0, 1, 5, 10, 15, 30, 60). 0 disables it. Metrics are billed through CloudWatch Logs. |
| `log_min_duration_statement` | `number` | no | Log queries slower than this many milliseconds. -1 disables slow-query logging. |
| `apply_immediately` | `bool` | no | Apply modifications immediately instead of during the maintenance window. Many changes cause a reboot, so keep this false in production. |
| `tags` | `map(string)` | no | Tags applied to every resource this module creates. |

## Outputs

| Name | Description |
|------|-------------|
| `db_instance_id` | Identifier of the RDS instance. |
| `db_instance_arn` | ARN of the RDS instance. |
| `db_endpoint` | Connection endpoint in host:port form. Resolvable only from inside the VPC. *(sensitive)* |
| `db_address` | Hostname of the database, without the port. *(sensitive)* |
| `db_port` | Port the database listens on. |
| `db_name` | Name of the initial database. |
| `db_secret_arn` | ARN of the Secrets Manager secret holding the RDS-managed master credentials. Passed to the iam module so the application role can read exactly this one secret. |
| `db_secret_kms_key_id` | KMS key ID encrypting the master user secret. The application role needs kms:Decrypt on this key. |
| `db_subnet_group_name` | Name of the database subnet group. |

## Notes

Requires Terraform `>= 1.10.0` and AWS provider `>= 5.70, < 7.0` (see `versions.tf`).
